# JourneyMap Ships(仮名、modid `jmships`)

Sable の船(Create Aeronautics の飛行船など)を、JourneyMap のミニマップと全体地図に「上から見たブロックの姿」で描く MOD。位置・回転・傾きに追従する。

- 対象: Minecraft 1.21.1 / NeoForge 21.1 / Sable 2.0.x / JourneyMap 6.x(窓口 v2)
- 入れる場所: 遊ぶ側(クライアント)だけ。ワールドを開く側には不要。
- Create Aeronautics 自体は必須ではない(Sable の船なら何でも映る)。

## いまの状態(2026-10-11)

0.1.0。試験用の世界で、水平の船・回転して傾いた船・動いている船の 3 隻が、ミニマップと全体地図の両方に正しい位置と向きで映ることを画面写真で確認した。**本番の環境ではまだ動かしていない。**

## 仕組み

1. `map/ShipScanner` が、クライアントが持っている船のブロックを読み、地図色(バニラの地図と同じ色)の立体の表にする。2 秒ごとに読み直す(大きさが変わったときはすぐ)。
2. `map/Projector` が、船のいまの姿勢で真上から見下ろし、1 ブロックあたり 4 画素の絵を作る。ブロックを「回った箱」として 1 画素ずつ当たり判定するので、斜めでも輪郭が正確。高さも記録し、段差にはバニラの地図と同じ明暗をつける。
3. `jm/ShipTexture` が絵を自前のテクスチャに描く。
4. `jm/ShipOverlays` が JourneyMap の公式の窓口(画像の貼り付け)でそのテクスチャを地図に貼る。JourneyMap は貼る位置をブロック単位でしか指定できないので、貼る枠は動かさず、枠の中で絵のほうを動かす(1/4 ブロック刻み)。船が枠の端に近づいたら枠を移す。

JourneyMap 本体には手を入れていない(mixin なし)。JourneyMap の更新で壊れにくい。

## 分かっている制限

- 映るのは、自分のクライアントに読み込まれている船だけ。遠くの船は映らない(離れると消える)。
- 屋根や島の下にいる船も、上に重ねて描く(隠さない)。
- 色はバニラの地図の色。JourneyMap の地形の色とは少し違う。ガラスなど地図色のないブロックは透ける。
- Create の「動く仕掛け」(プロペラなど、ブロックでなくなっている部分)は描かない。
- 名前は全体地図でマウスを重ねたときだけ出る。
- 動いている船は毎ティック描き直す。絵を作る計算は、長さ 40 ブロック級で約 1.3 ミリ秒(机上の計測)。それより大きい船は自動で粗く描いて同じくらいに抑える(見える面が 6000 マス以上で 1 ブロック 2 画素、25000 マス以上で 1 画素)。本番の大きな船での体感は未確認。
- 試験で通っていない経路: 船の大きさが変わって絵を作り直すところ、船のチャンクがまだ届いていないときに前の絵を保つところ。

## 作り方・試し方

```
python tools/run_gradle.py run-logs/build.log build          # jar は build/libs/jmships-0.1.0.jar
python tools/run_gradle.py run-logs/visual.log runVisual     # 試験用のクライアントが 1 分ほど開いて自動で閉じる
```

- `runVisual` は、平らな世界を新しく作り、船を 3 隻組み立てて、画面写真を `run-visual/screenshots/jmships-0*.png` に 4 枚残す。合否は写真を目で見て決める(結果ファイルは「撮れた」ことしか言わない)。
- 単体試験(`build` に含まれる)は、絵を作る計算だけを確かめる(8 件)。
- コンパイルには、Sable の jar(`../ColonyPatchServer/test-jars/` と共用)と JourneyMap の窓口の jar(`libs/`)を使う。`test-jars/` の JourneyMap 本体は試験用。
